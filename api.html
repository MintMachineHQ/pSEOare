Each city, asset and country has one. The slugs match the page filenames, so /api/cities/kazan.json is the same record behind https://pseoare.pages.dev/kazan-average-monthly-temperature-rainfall.

Cities API

One request per city. Monthly climate averages for that city. No key, no rate limit, no attribution required.

Aggregate: https://pseoare.pages.dev/api/cities.json

{
  "city": "Kazan",
  "annual_mean_c": 3.1,
  "warmest_month": "Jul",
  "swing_c": 33.3
}

Holidays API

Public holidays for one country, or for every tracked country. No key, no rate limit, no attribution required.

Aggregate: https://pseoare.pages.dev/api/holidays.json

{
  "country": "Cyprus",
  "local_name": "Χριστούγεννα",
  "date": "2027-12-25",
  "weekday": "Saturday"
}

Crypto API

365-day high, low, latest and range position for each tracked asset. No key, no rate limit, no attribution required.

Aggregate: https://pseoare.pages.dev/api/crypto.json

{
  "asset": "Bitcoin",
  "high_12m": 124739.81,
  "low_12m": 58566.09,
  "pct_above_low": 44.8
}

Terms

  • Figures come from public open APIs and are on a best-effort basis; check the source page before relying on a number.
  • Attribution is appreciated but not required.
  • Please cache rather than poll aggressively; the data only changes once a day.
