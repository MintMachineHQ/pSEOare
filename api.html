Climate API

Monthly climate averages for every tracked city. No key, no rate limit, no attribution required.

Endpoint: https://pseoare.pages.dev/api/climate.json

{
  "city": "Kazan",
  "annual_mean_c": 3.1,
  "warmest_month": "Jul",
  "swing_c": 33.3
}

Holidays API

Public holidays with dates, weekdays and local names. No key, no rate limit, no attribution required.

Endpoint: https://pseoare.pages.dev/api/holidays.json

{
  "country": "Cyprus",
  "local_name": "Χριστούγεννα",
  "date": "2027-12-25",
  "weekday": "Saturday"
}

Crypto API

365-day high, low and latest for each tracked asset. No key, no rate limit, no attribution required.

Endpoint: https://pseoare.pages.dev/api/crypto.json

{
  "asset": "Bitcoin",
  "high_12m": 124739.81,
  "low_12m": 58566.09,
  "pct_above_low": 44.8
}

Terms
